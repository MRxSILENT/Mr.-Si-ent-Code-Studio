# Mr. Si!ent Code Studio — Tabbed Monaco editor
This version has **one Monaco editor area**. Click HTML, CSS, or JavaScript tabs to switch the active file in the same editor; each language's code remains saved independently. Live preview updates automatically.

Features: Monaco syntax highlighting, tabs, live preview, Run, Reset, dark/light theme, fullscreen preview, draggable editor/preview divider, ZIP export with separate source files and preview.

Upload index.html, style.css, script.js to GitHub repository root and enable Settings → Pages → main → root. CDN internet required.
